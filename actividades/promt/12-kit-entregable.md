## Autoevaluación

Antes de entregar, califíquese contra la misma rúbrica con la que se va a
calificar. Si algún criterio está flojo, todavía está a tiempo.

| Criterio | Qué se mira | % | Mi calificación |
|---|---|---|---|
| Estructura | Presencia de rol, contexto, tarea, formato y restricciones en cada plantilla | 30 | |
| Reutilización | Variables bien definidas: sirve para varios casos, no para uno | 25 | |
| Evidencia de prueba | Cada plantilla probada con 2 casos y **ajustada después** | 25 | |
| Criterio propio | Regla personal de verificación y lista de datos que no subo | 20 | |

**Lo que más se cae en este entregable:** las pruebas quedan escritas como
«funcionó bien» sin que la plantilla haya cambiado. Si después de dos pruebas la
plantilla quedó idéntica, o no la probó de verdad, o los dos casos eran el mismo
caso.
